# Update the Codex Quota gallery and overview

Codex Quota 0.2.2 shows the remaining quota and time until reset on one scale. The overview explains how to read the marker and how to change the refresh interval or ring placement.

The four English screenshots show the Plus card in chat, the sidebar settings, the mobile layout and the expiry dates of three manual resets. Percentages, counts and dates are demo data.

To try it, open the ring in a Codex chat and select the gear. Click the interval or focus it with Tab, then change the value to reveal Save. Open the lightning bolt to inspect the expiry dates.

The existing Git source tracks `^0.2.0`, which includes [v0.2.2](https://github.com/ai-babai/bb-plugin-codex-quota/releases/tag/v0.2.2). Existing 0.2.x installs can update with `bb plugin update codex-quota`.
